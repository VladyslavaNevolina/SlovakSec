# Вебсайт-візитівка «Економічна безпека країни»

**Автор:** Неволіна Владислава Едуардівна  
**Заклад освіти:** Державний торговельно-економічний університет (ДТЕУ), Факультет міжнародної торгівлі та права (ФМТП), спеціальність «Міжнародні відносини», 1 курс, 23 група  
**Рік створення:** 2026

## Структура проєкту
- `index.html` — головна сторінка «Про автора» (відомості про студентку, навчання, наукові інтереси та контакти).
- `slovakia.html` — аналітична сторінка «Економічна безпека Словацької Республіки» (загальна характеристика країни, 12 ключових індикаторів із пороговими значеннями та фільтром, 3 інтерактивні графіки за 2015–2025 рр., основні загрози, висновок і джерела даних).
- `style.css` — адаптивні стилі в академічному університетському дизайні.
- `script.js` — мобільне навігаційне меню, фільтрація таблиці індикаторів та побудова інтерактивних діаграм через Chart.js.
- `assets/` — папка для додаткових файлів/ресурсів проєкту.

## Інструкція з публікації на GitHub Pages
1. Зареєструйтеся або увійдіть у свій обліковий запис на [github.com](https://github.com).
2. Натисніть **New repository** (Створити репозиторій), введіть назву (наприклад, `economic-security-slovakia`), оберіть **Public** і натисніть **Create repository**.
3. Натисніть **uploading an existing file**, перетягніть усі файли з розпакованого архіву (`index.html`, `slovakia.html`, `style.css`, `script.js`, `README.md`) у корінь репозиторію та натисніть **Commit changes**.
4. Перейдіть у вкладку **Settings** репозиторію → у лівому меню оберіть **Pages**.
5. У блоці **Build and deployment → Branch** виберіть гілку `main` (папка `/ (root)`) і натисніть **Save**.
6. Через 1–2 хвилини оновіть сторінку — зверху з’явиться активне посилання на ваш опублікований сайт вигляду `https://<ваш-логін>.github.io/economic-security-slovakia/`.
